I've invented a game based on tetris (let's call the project Latin Tetris) which tests knowledge of the first declension singular in Latin, although it could work equally well for other languages and learning verb conjugations. I tried to get chat gpt to create a level for each of the declensions, singular and plural,but chat gpt couldn't cope. I tried using cursor ai, rosebud ai, chat gpt and replit but they were either too expensive or made too many errors. 
If you're reading this and looking for a coding project, I would appreciate help. Currently the music is tetris original but I could change this to avoid copyright infringement.
